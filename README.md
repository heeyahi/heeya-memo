# 나와의 메모 🌰

카카오톡 '나와의 채팅' 대신 쓰는 **채팅형 메모 웹앱**입니다.
단일 HTML 파일로 동작하고, 데이터는 사용하는 기기의 브라우저(localStorage)에만 저장됩니다.

## 기능

- 💬 날짜별로 쌓이는 말풍선 메모 (수정·삭제·복사·폴더 이동·고정)
- 📁 폴더 여러 개 (추가·이름 변경·아이콘 변경·삭제)
- ✨ 제목·해시태그 붙여서 쓰기
- 🖼 사진 첨부 (자동 리사이즈·압축 후 저장)
- 📅 캘린더 탭 — 메모가 있는 날짜에 점 표시, 날짜별 모아보기
- 🔍 검색·모아보기 — 키워드, 태그, 사진만 보기
- 🌙 다크 모드 / 💾 JSON 백업 내보내기·가져오기
- 📲 아이폰 '홈 화면에 추가'로 앱처럼 실행 (PWA)

## 사용

`index.html`을 열면 바로 실행됩니다. 별도 설치나 인터넷 연결이 필요 없습니다.

아이폰 사파리에서 아래 주소로 접속 → 공유 버튼 → **홈 화면에 추가**:

https://heeyahi.github.io/heeya-memo/

> 메모는 서버로 전송되지 않고, 브라우저 저장소에만 남습니다.
> 기기를 바꾸거나 브라우저 데이터를 지우기 전에 **설정 → 백업 내보내기(JSON)** 로 보관하세요.
